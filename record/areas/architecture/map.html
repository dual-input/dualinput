Links and channels

How each link carries its messages and how the core knows the other end is alive, then the eight channels inside each connection between cores.

When QUIC's queue is short of room, the core keeps only each channel's newest one-off packet and hands them over in a fixed order: heartbeat, flight model, ATC audio, avatars, then traffic. Through a relay, it paces everything below the cap the relay list gives. 035
