=== Who holds a killed process open, from PowerShell with no administrator
A script started a program as the app starts the core, with CREATE_NO_WINDOW, held one handle to it, killed it with
TerminateProcess after 1.5s or 2.5s, and read the process object's handle count through NtQueryObject until only its own
handle was left. It named other holders by duplicating each Process handle the system's handle table lists, from every
program it could open, and comparing objects; the table gave no object addresses to a caller without administrator.
"handles" counts the script's own handle too.

          programs the script could open
