# Record

The documents agents write for Crosscheck live here, in the kinds [writing.md](writing.md) describes.
Documentation people write for other people lives in `docs/` instead.

- [writing.md](writing.md): how everything agents write for this repository is written, including the kinds of document, the sentence rules, how to mark evidence, and the words the lint flags.
- [learn/foundations/outline.md](learn/foundations/outline.md): the foundations course, the concepts we need to build Crosscheck, in the order we'll learn them, with the depth each one gets.
- [learn/chapter-guide.md](learn/chapter-guide.md): how a chapter of the learning material is shaped, pitched, and sourced.
- [areas/commbus/log.md](areas/commbus/log.md): what our experiments found about reading an aircraft's CommBus traffic from panel JavaScript, on the Synaptic A220, the A2A PA-24, and the iniBuilds A350.
